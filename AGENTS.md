# Agent instructions

## Project

`python-scid` is a Python 3.10+ library for reading, writing, and searching
SCID4 and SCID5 chess databases. It uses `python-chess` for PGN games and board
positions.

## Code map

- `scid/database.py`: public `ScidDatabase` API and database file lifecycle.
- `scid/index.py`, `scid/namebase.py`: SCID4/SCID5 index and namebase codecs.
- `scid/gamedata.py`, `scid/moves.py`: game-blob and move codecs.
- `scid/search.py`: header, position, material, and opening-tree searches.
- `scid/quality.py`: Stockfish/UCI-based main-line move-quality analysis.
- `scid/constants.py`, `dates.py`, `eco.py`, `matsig.py`, `homepawns.py`,
  `stored_lines.py`, `_filebuf.py`: format constants and lower-level helpers.
- `tests/`: unit and integration tests. Shared database fixtures are looked
  up under `~/games/chess`; tests skip when a fixture is missing. Some tests
  against the `freechess` database are comparatively large.

## Development and tests

- Run the test suite with `pytest -q` (requires the project dependency
  `chess` and the development dependency `pytest`).
- No formatter, linter, or type checker is configured in `pyproject.toml`.
- Keep Python 3.10 compatibility and follow the existing style: type
  annotations, focused helpers, and descriptive docstrings.
- When changing binary encodings, preserve SCID4/SCID5 compatibility and add
  round-trip or fixture-based tests for both formats where applicable.
- Search optimizations must not change results; test both the pre-filter and
  the full decode/replay behavior when modifying search logic.
- Quality analysis uses an external UCI engine. Keep tests deterministic with
  an engine stub; do not require Stockfish to be installed in the test suite.
  Batch checkpoints are annotated PGN files and must not modify source databases.

## Data safety

- Tests and experiments that write databases must use pytest's temporary
  paths. Do not modify or overwrite databases in `~/games/chess`.
- Do not add generated bytecode, local database files, or other test artifacts
  to the source tree.
